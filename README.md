# 🐍 Snake Game

옛날 닌텐도 휴대용 게임기 외관 디자인을 적용한 브라우저 스네이크 게임입니다. HTML / CSS / JS 순수 바닐라로 작성되었습니다.

## 실행 방법

별도 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

```bash
# 정적 서버로 실행하고 싶다면 (선택 사항)
python -m http.server 8000
```

## 조작법

| 입력 | 동작 |
| --- | --- |
| 방향키 (↑ ↓ ← →) | 뱀 이동 |
| Space | 게임 시작 / 일시정지·재개 |
| 화면 하단 D-패드 | 방향키와 동일 (터치/마우스 조작) |

## 게임 규칙

- 400×600 캔버스, 40px 격자 (10×15칸)
- 빨간 사과를 먹으면 뱀이 길어지고 점수 +1
- 파란 사과(다이어트 사과)는 랜덤한 시점에 나타났다 사라지며, 먹으면 꼬리 1칸이 줄고 점수 -1 (0 미만으로는 내려가지 않음)
- 사과는 일정 시간이 지나면 서서히 투명해지다 사라지고, 다른 랜덤한 위치에 다시 생성됨
- 벽이나 자기 몸에 부딪히면 게임 오버
- 뱀이 보드를 가득 채울 만큼 자라면 승리(YOU WIN)
- 최고 점수는 브라우저 LocalStorage에 저장되어 다음 방문에도 유지됨

## 난이도

시작 화면에서 이동 속도를 선택할 수 있습니다.

| 난이도 | 틱 간격 |
| --- | --- |
| 쉬움 | 200ms |
| 보통 (기본값) | 150ms |
| 어려움 | 100ms |
| 매우 어려움 | 50ms |

## 파일 구조

```
index.html   # 마크업 (캔버스, HUD, 오버레이, 콘솔 외관)
style.css    # 레트로 휴대용 게임기 디자인
script.js    # 게임 로직 (이동, 충돌, 점수, 렌더링)
```
